Sniper's own UDB-format overlay, applied after the upstream RISC-V Unified
Database and the IME 0.9 contribution.  It carries only what those do not
define as instructions (vsetlambda).  Same layout as a UDB checkout, so
`gen_isa.py --udb <upstream> --udb <ime overlay> --udb tools/riscv/overlay`.

`inst/Ztt/` and `ext/Ztt.yaml` are generated by `tools/riscv/gen_ame_udb.py`
from the AME working group's specification source
(riscv/riscv-attached-matrix-extension): AME has no published UDB yet, so
the converter is its UDB source until it does.  Regenerate when the draft
moves; the converter checks every encoding against the repository's own
mask/match table.
